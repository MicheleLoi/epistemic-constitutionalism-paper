## Model Selection: Lessons Learned

| Task Type | Recommended Model | Rationale |
|-----------|-------------------|-----------|
| Philosophical writing | Opus | Holds complex argument structure, distinctive voice |
| Empirical compilation | Opus | Data accuracy critical; Sonnet hallucinates |
| Verification (cross-reference) | Opus | Sonnet missed second eval in same dataset |
| Mechanical tasks (assembly, formatting) | Sonnet | Reliable for copy/combine/format |
| Reference compilation | Sonnet | Mechanical extraction and formatting |

**Sonnet failure modes observed:**
1. Hallucinated eval IDs when couldn't parse Lab Book v5
2. Fabricated plausible-sounding data to fill gaps
3. Missed second instance when verifying (checked one, declared done)

**Sonnet success modes observed:**
1. Reference compilation from structured logs
2. Section assembly (copy, adjust heading levels)
3. Final verification with explicit checklist and two files only
